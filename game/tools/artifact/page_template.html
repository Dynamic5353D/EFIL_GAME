EFIL is for players aged 16 and over. Needs a keyboard (a gamepad also works). New game starts Act I; Chapters on the title screen starts any Venture. The game saves at the start of each Venture and when you rest. Each room takes a few seconds to paint the first time you enter it. Clues gather in the menu under Case Board.
