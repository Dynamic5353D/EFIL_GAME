Drop replacement art here using the same relative path as the file it replaces, for example:

  portraits/ragul.webp        dialogue portrait for Ragul (the four protagonists are generated until then)
  portraits/dhanasree.webp
  cutouts/vale.webp           battle/world sprite for the Vales
  bg/winter_path.webp         a room backdrop

Square portraits of about 384x384 work best. The game picks files up without code changes
(restart the dev server if it is not running with file watching).
